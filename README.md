# Insurance Fraud Detection System

This project is a web based application that detects fraudulent vehicle insurance claims using machine learning.

The system allows users to create an account, log in, and submit insurance claim details through a web form. After the user submits the claim information, the trained machine learning model analyzes the data and predicts whether the claim is fraudulent or genuine.

The goal of this system is to help insurance companies identify suspicious claims early and reduce financial losses caused by insurance fraud.

The application is built using Flask and Python for the backend and uses machine learning algorithms trained on an insurance claims dataset to perform fraud detection.

When a user submits claim details such as accident information, claim amount, number of vehicles involved, injury details, witnesses, and police report availability, the model evaluates the patterns and returns a prediction indicating whether the claim is likely fraudulent or legitimate.
